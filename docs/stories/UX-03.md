# UX-03 — Make overlays and unsaved-work navigation predictable

**Status:** In progress · **Priority:** P0  
**Feature:** [Consistent interface and editorial experience](../features/ui-ux-consistency.md)  
**Dependencies:** [UX-01](UX-01.md), [UX-02](UX-02.md)

As an editor using keyboard, pointer, or touch, I want dialogs and navigation to behave consistently, so my work and place in the app are preserved.

## Current evidence

Add source and New story focus an input and support Escape, but do not implement a shared focus trap or restore contract. StoryContentViewer closes on backdrop click while editing. The mobile sidebar has a separate keyboard implementation.

**Surfaces:** [add-source-dialog.tsx](../../src/app/add-source-dialog.tsx) · [new-story-dialog.tsx](../../src/app/new-story-dialog.tsx) · [radar-dashboard.tsx](../../src/app/radar-dashboard.tsx) · [creative-draft-workspace.tsx](../../src/app/creative-draft-workspace.tsx) · [story-workspace-page-client.tsx](../../src/app/topics/[topicId]/stories/[storyId]/story-workspace-page-client.tsx).

## Acceptance criteria

1. Provide a common dialog/drawer pattern with name, initial focus, focus containment, background inertness, scroll handling, Escape, and focus return. Reuse it for creation dialogs, content editing, and confirmation surfaces.
2. Preserve an in-progress draft when closing an editor would discard input. Offer clear Save and leave, Discard, and Keep editing actions where saving is supported; do not require confirmation for harmless navigation.
3. Apply the dirty-state guard to app links, Topic switches, editor close, and supported browser navigation. Use the browser's native unload warning for reload/close where necessary.
4. Show the consequence of changing context during an active request. Do not imply that closing a dialog cancels a server operation unless cancellation exists.
5. Standardize overflow-menu Escape and focus behavior. If menu roles are used, implement their keyboard contract; otherwise use accessible native disclosure semantics.
6. Return focus to a meaningful destination after a trigger disappears or a modal replaces another modal.

## Validation

Complete Add source and New story using only Tab, Shift+Tab, Enter, and Escape. Try backdrop close with unsaved content, browser Back during an edit, and a completed upload after closing its view.

## Scope and delivery

Reuse existing side-effect controls; this story does not introduce cancellation or background persistence to services that lack them.
