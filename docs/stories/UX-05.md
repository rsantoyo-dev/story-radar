# UX-05 — Preserve navigation context and make every destination accurate

**Status:** In progress · **Priority:** P0  
**Feature:** [Consistent interface and editorial experience](../features/ui-ux-consistency.md)  
**Dependencies:** [UX-01](UX-01.md), [UX-03](UX-03.md), [UX-04](UX-04.md)

As an editor, I want links and Back to return me to the expected work, so I do not need to find the same Story or configuration again.

## Current evidence

Overview's In production link still targets #stories, which now resolves to Discover. The editorial-line help link targets #configuration. Processes currently links to Today. The standalone studio has a separate header, and returnHref retains a section hash rather than the complete list state.

**Surfaces:** [radar-dashboard.tsx](../../src/app/radar-dashboard.tsx) · [dashboard-navigation.ts](../../src/app/dashboard-navigation.ts) · [topic-overview-panel.tsx](../../src/app/topic-overview-panel.tsx) · [editorial-lines-panel.tsx](../../src/app/editorial-lines-panel.tsx) · [story-workspace-page-client.tsx](../../src/app/topics/[topicId]/stories/[storyId]/story-workspace-page-client.tsx) · [page.tsx](../../src/app/help/page.tsx).

## Acceptance criteria

1. Create a destination map covering old anchors and new sections. In production opens Production; line configuration opens Editorial strategy/Lines; help and channel links use current labels and destinations.
2. Persist relevant Topic, line, list filters, sort, selection context, and scroll position when opening a Story and returning. Scope stored state to its Topic and recover safely when the record is gone.
3. Keep the current section when switching Topics where meaningful, reset incompatible entity state, and reject late responses from the previous context.
4. Use consistent compact Topic identity, page title, return control, and breadcrumb behavior across the dashboard, standalone studio, and Help.
5. Make Processes open a real supported execution view or rename its current Today shortcut to match its behavior. An aggregated process center requires actual job data; do not add a decorative control.
6. Keep legacy bookmarks working, and integrate the future account menu only with the AUTH session work.

## Validation

Follow every Overview, Help, profile, source, and channel cross-link. Open a filtered Story, reload, use browser Back/Forward, switch Topic, and retry after a missing Story response.

## Scope and delivery

Related work: OVW-06 and AUTH-03–06. Do not replace server authorization or introduce a second router solely for appearance.

## Implementation progress — September 28, 2026

- Overview cards now open Discover, Production, or publication history as labeled. The editorial-line help link opens the actual management view, which now renders in Editorial strategy. The old “Processes” shortcut is labeled Today.
- A Story return link now preserves the selected-story hash instead of discarding it. Legacy hash mapping tests pass.
- Review filters, sort choices, line filter, and shortlist view now persist in session storage scoped to the Topic. Opening the standalone studio stores a short-lived return position; its return link restores the dashboard's section and scroll position after the Story data reloads. A stored collector connection reloads the dashboard read-only on return.
- Remaining: preserve bulk selection safely across navigation, verify browser Back/Forward and missing-record recovery, and complete the authenticated browser review. The local database currently lacks `knowledge_documents.object_key`, which blocks the Sources screen.
