# UX-20 — Unify publication history, Story links, and metrics

**Status:** In progress · **Priority:** P1  
**Feature:** [Consistent interface and editorial experience](../features/ui-ux-consistency.md)  
**Dependencies:** [UX-01](UX-01.md), [UX-02](UX-02.md), [UX-03](UX-03.md), [UX-04](UX-04.md), [UX-05](UX-05.md), [UX-18](UX-18.md)

As an editor, I want to trace a post to its exact Story and creative version and understand its results, so I can learn from published work.

## Current evidence

The gallery and Story results implement separate metric values and historical image views. Linking uses nested Story/draft/batch selectors. PublicationQuickControl writes a manual status on select change and labels states like provider-confirmed publication.

**Surfaces:** [instagram-gallery-panel.tsx](../../src/app/instagram-gallery-panel.tsx) · [story-instagram-results.tsx](../../src/app/story-instagram-results.tsx) · [radar-dashboard.tsx](../../src/app/radar-dashboard.tsx).

## Acceptance criteria

1. Use a consistent publication card/detail view with account, date/zone, destination, linking state, published-version identity, and accessible media fallback.
2. Reuse one metric presentation across gallery and Story results, preserving null, unsupported, stale, permission-denied, and zero as distinct. Show sync time, denominator, and definition for ratios.
3. Make linking a deliberate review/save action with searchable Story selection and optional exact-version selection. Preserve the source of the link and handle unavailable historical artifacts without substituting the current draft.
4. Label manual tracking explicitly and explain that editing it does not send or schedule content. Distinguish it visually from provider-confirmed posts and worker jobs.
5. Keep filters, cursor/load-more state, and Story return paths consistent. A failed thumbnail must not hide copy, history, or metrics.
6. Keep historical review read-only; removing a local association does not delete the remote post. Do not combine metrics across accounts, destinations, or versions without an explicit supported aggregate.

## Validation

Compare supported zero versus unavailable metrics, expired thumbnails, a deleted historical artifact, manual tracking, automatically linked publication, and a corrected link. Confirm both results surfaces show equivalent values and freshness.

## Scope and delivery

Reuse IG contracts and PUB-12/15/18 as those become available. Do not add invented cross-platform comparisons or silently rewrite historical attribution.

## Implementation progress — September 28, 2026

- Selected-Story publication marks are explicitly labeled manual tracking. Choosing a status no longer writes immediately: the editor reviews it and activates Save manual status. The UI explains that this action neither sends nor schedules content.
- Remaining: unified provider-confirmed history and metrics, deliberate media linking, historical review, and mobile/state fixtures.
