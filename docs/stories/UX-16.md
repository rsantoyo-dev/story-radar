# UX-16 — Create a focused script composer with a useful preview

**Status:** In progress · **Priority:** P0  
**Feature:** [Consistent interface and editorial experience](../features/ui-ux-consistency.md)  
**Dependencies:** [UX-01](UX-01.md), [UX-02](UX-02.md), [UX-03](UX-03.md), [UX-04](UX-04.md), [UX-05](UX-05.md), [UX-15](UX-15.md)

As an editor, I want to edit and preview the selected piece while understanding its review state, so I can approve the right script confidently.

## Current evidence

Script displays a text-preview strip followed by setup, the full editor, several generation/repair/save actions, approval, and companion creation. Saved studies and copyable outputs use additional disclosures; the text preview always says 'image pending'.

**Surfaces:** [creative-draft-workspace.tsx](../../src/app/creative-draft-workspace.tsx) · [creative-draft-workspace.module.uxdsl](../../src/app/creative-draft-workspace.module.uxdsl).

## Acceptance criteria

1. Use one script workspace with an ordered piece list, selected-piece editor, and persistent preview. On smaller screens provide an explicit Edit/Preview switch with retained selection and edits.
2. Distinguish the text preview from rendered media using actual availability. Show caption, hashtags, and accessibility text in a consistent destination without duplicating competing editors.
3. Keep Save and Review/Approve at a stable location. Generation, repair, and creating a new version are secondary contextual actions with clear effects and saved-input requirements.
4. Attach factual/quality findings to the affected copy when possible, summarize unresolved blockers, and distinguish advisories from required corrections.
5. Expose version history consistently; historical content is read-only, and creating an improved version preserves the original. Copy actions identify whether they include visible text, caption, or technical prompts.
6. Label companion output as a social Story format to distinguish it from the platform's editorial Story entity. Preserve its parent linkage and separate approval.
7. Provide keyboard-accessible piece ordering with piece-specific action labels. Structural edits clearly explain any effect on images and approval.

## Validation

Edit a carousel and a single-image draft, switch pieces, copy the caption, resolve a blocker, save and approve the exact revision. Compare text-only and generated-image states and a read-only historical draft.

## Scope and delivery

Reuse draft and quality-review contracts. Preview/format work coordinates with PUB-14; no independent generation pipeline or implicit approval.

The editor exposes one selected piece at a time with keyboard accessible selectors and piece-specific reorder labels. Remaining: responsive edit/preview mode, contextual findings, and complete historical comparison.
