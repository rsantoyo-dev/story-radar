# UX-14 — Turn document extraction into a clear evidence workspace

**Status:** In progress · **Priority:** P1  
**Feature:** [Consistent interface and editorial experience](../features/ui-ux-consistency.md)  
**Dependencies:** [UX-01](UX-01.md), [UX-02](UX-02.md), [UX-04](UX-04.md), [UX-13](UX-13.md)

As an editor, I want to see whether a document is ready and select the material for a Story, so extraction and evidence selection feel like a guided task.

## Current evidence

Document upload, shared links, extraction status, chapters, dossier title, and Story creation are embedded in TopicConfigurationPanel. Several actions are repeated on each document and chapter.

**Surfaces:** [topic-configuration-panel.tsx](../../src/app/topic-configuration-panel.tsx) · [topic-configuration-panel.module.uxdsl](../../src/app/topic-configuration-panel.module.uxdsl).

## Acceptance criteria

1. Give each document a compact row with title, Topic links, extraction state, last attempt, and one next action: inspect, retry, or select material.
2. Open document details in a focused workspace with readable section/chapter navigation and visible source/page provenance. Long extracted text does not crowd the catalog.
3. Show selected chapters and the dossier title in a stable selection summary with a count and clear Create Story action. Preserve selection during inspection and recoverable errors.
4. Distinguish creating a candidate from linking a document or retrying extraction. Display existing candidate links when returned by the current contract.
5. Keep shared-document and Topic-link scope explicit; a retry or unlink must target the selected record and preserve historical Story evidence.
6. Provide corrupt/unsupported file, processing, partial result, failed extraction, empty text, and no-selection states using shared patterns.

## Validation

Inspect a large multi-chapter document, select discontiguous chapters, retry a failed extraction, switch details, and create a Story with preserved page provenance.

## Scope and delivery

Reuse SRC-05 and document/dossier endpoints; do not introduce another extraction engine or recreate successful source records.
