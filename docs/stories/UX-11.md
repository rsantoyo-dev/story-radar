# UX-11 — Unify palette, logo, reference, and character editors

**Status:** In progress · **Priority:** P1  
**Feature:** [Consistent interface and editorial experience](../features/ui-ux-consistency.md)  
**Dependencies:** [UX-01](UX-01.md), [UX-02](UX-02.md), [UX-03](UX-03.md), [UX-04](UX-04.md), [UX-10](UX-10.md)

As an editor, I want familiar asset controls and clear previews, so I can manage a consistent visual brand without learning a different form for each asset type.

## Current evidence

Palette, numbering, logo placement, reference cards, character slots, and Story photos each use different upload, selection, preview, and save treatments. The palette already includes contrast diagnostics and an assistant with undo.

**Surfaces:** [creative-profile-fields.tsx](../../src/app/creative-profile-fields.tsx) · [creative-palette-assistant.tsx](../../src/app/creative-palette-assistant.tsx) · [creative-brand-image-editor.tsx](../../src/app/creative-brand-image-editor.tsx) · [story-photos-panel.tsx](../../src/app/story-photos-panel.tsx).

## Acceptance criteria

1. Use a shared upload/preview/status pattern with supported type and size guidance, selection, upload progress or honest indeterminate state, error recovery, and accessible removal.
2. Give palette entries consistent labels, roles, usage share, and validation. Preserve existing contrast diagnostics; distinguish a suggested palette from an applied, unsaved profile change and preserve Undo.
3. Preview logo scope, placement, backdrop, and carousel numbering using the effective settings. Clearly label a sample composition as a preview.
4. Use a scannable reference library with thumbnail, name, kind, active state, permission, and revision before detailed guidance. Keep replace, archive, and download distinct.
5. Use the same selected-state treatment for characters and per-slide reference pickers, while preserving their current limits and historical versions.
6. Explain asset scope: Topic brand references, fictional characters, and Story evidence photos are different records. Required provenance and transmission permission remain explicit.

## Validation

Test invalid upload, missing historical bytes, revoked permission, inactive references, maximum selections, failed preview, and palette Undo. Compare controls in the profile library and Story photo picker.

## Scope and delivery

Reuse BRAND and IMG contracts. Unified presentation does not merge the libraries or weaken documentary image restrictions.

## Implementation progress — September 28, 2026

- Story evidence photos now validate type and size before upload, announce upload/removal failures as errors, and explain scope and selection limits in the picker. Palette Undo is offered only while the applied suggestion is intact, so it cannot overwrite later manual edits. Remaining: shared controls across Topic logos, brand references, and characters, plus browser validation.
