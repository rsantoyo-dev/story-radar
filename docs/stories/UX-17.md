# UX-17 — Unify visual review, image editing, and version history

**Status:** In progress · **Priority:** P0  
**Feature:** [Consistent interface and editorial experience](../features/ui-ux-consistency.md)  
**Dependencies:** [UX-01](UX-01.md), [UX-02](UX-02.md), [UX-03](UX-03.md), [UX-04](UX-04.md), [UX-16](UX-16.md)

As an editor, I want to inspect and improve one image while seeing the whole sequence, so I can approve a coherent publication without losing previous versions.

## Current evidence

Each CreativeAssetCard combines image, place evidence, text-drift warnings, brand editing, regeneration prompt, and actions. Generative edits, original comparisons, and saved batches are spread across cards and history panels.

**Surfaces:** [creative-draft-workspace.tsx](../../src/app/creative-draft-workspace.tsx) · [creative-brand-image-editor.tsx](../../src/app/creative-brand-image-editor.tsx) · [creative-documentary-panel.tsx](../../src/app/creative-documentary-panel.tsx) · [story-photos-panel.tsx](../../src/app/story-photos-panel.tsx).

## Acceptance criteria

1. Provide a thumbnail strip, selected-image canvas, and contextual inspector. Show image order, version, text correspondence, generation state, and approval separately.
2. Use the same Save change, Apply change, Compare, and Review vocabulary across generative editing and selective text updates. State which image/version will change and preserve other units.
3. Make the base image and result available for comparison at the same scale. Coordinate version selection and adoption with IMG-04/05; unsupported historical adoption is not exposed as an active control.
4. Keep original photos, maps, source attribution, and documentary restrictions accessible near the preview. Distinguish verified source material from conceptual illustration.
5. Group prompts, provider metadata, and detailed selection diagnostics under Advanced. Required evidence and permission failures remain visible.
6. Show image-level failures and bounded retry where the existing service allows it. A pending result or changed text never appears approved or ready for delivery.
7. Maintain actual output aspect ratio, accessible image labels, loading placeholders, and usable zoom/fit controls on desktop and mobile.

## Validation

Update slide 2 in a three-slide carousel, compare it with its base, and verify the other files remain unchanged. Exercise stale text, revoked reference permission, failed generation, documentary original comparison, and a historical batch.

## Scope and delivery

IMG-04/05 own any missing selection/adoption behavior, and IMG-03 owns deterministic recomposition. Complete those dependencies before claiming the respective interactions done; do not simulate them with mutable current images.

## Implementation progress — September 28, 2026

- Visual review now provides ordered thumbnails with version and status and opens a single image’s existing preview and controls. Other image cards stay mounted when selection changes. The selected image can switch between fitted and actual-size inspection, and a missing-place photo action opens the matching script slide. Remaining: coordinated same-scale comparison, advanced inspector grouping, mobile zoom validation, and IMG-dependent adoption behavior.
